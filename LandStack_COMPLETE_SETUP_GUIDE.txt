LAND STACK
COMPLETE PROJECT SETUP & RUN GUIDE
==================================

1. PROJECT OVERVIEW
-------------------
Land Stack is a local web application that connects:

    Frontend (HTML/JavaScript)
            |
            v
    FastAPI Backend
            |
            v
    Python + python-oracledb
            |
            v
    Oracle Instant Client (64-bit, Thick Mode)
            |
            v
    Oracle Database (ORCL)

The current frontend is an HTML/JavaScript application with Leaflet for
the map and a search interface. The frontend calls the FastAPI backend
through:

    http://127.0.0.1:8000/search?term=...

3. IMPORTANT: DO NOT SHARE THE VENV FOLDER
--------------------------------------------
The folder:

    backend\venv\

contains installed Python packages and generated files.

included in the project ZIP.

when making the final project ZIP.

22. TROUBLESHOOTING
-------------------
A. "python was not found"

Make sure a normal Python installation is installed and selected in VS Code.

Check:

    python --version

Also check:

    where.exe python


B. "No module named fastapi"

Activate the venv:

    .\venv\Scripts\Activate.ps1

Then install:

    python -m pip install fastapi uvicorn oracledb


C. "No module named venv"

The selected Python installation is missing the venv module.
Use a normal Python installation that includes pip and venv.


D. DPY-3010

This happens when python-oracledb Thin mode is used with an unsupported
old Oracle Database version.

The working project uses Thick mode instead.


E. DPI-1047

This indicates a problem loading the Oracle Client library.

Check that:

    E:\hackathon\oraclex64\instantclient_23_26\oci.dll

exists and that its architecture matches Python.

Working setup:

    Python = 64-bit
    Client = 64-bit


F. Oracle service is not running

Open:

    services.msc

Check:

    OracleServiceORCL

It should be:

    Running

Also check the Oracle listener service.


G. FastAPI gives Internal Server Error

Look at the terminal running Uvicorn.

The browser may only show:

    Internal Server Error

The actual Python/Oracle error will be printed in the terminal.

29. SECURITY NOTES FOR FUTURE DEVELOPMENT
------------------------------------------
For a production version:

    - Store credentials in environment variables/secrets.
    - Restrict CORS to trusted frontend origins.
    - Use authentication/authorization for private records.
    - Add input validation and rate limiting.
    - Use HTTPS.
    - Avoid exposing unnecessary personal/ownership data.
    - Add audit logging.
    - Use real GIS data instead of demo coordinates.
    - Avoid shipping development credentials in source code.
